This Python project creates a life simulation with some colleagues with needs like energy, and social discussions.
Several colleagues are able to do some actions to level up their energy or social levels like rest or discuss.
At each turn, each colleague loose some points in their energy or social bars because they have to work most of the time.
But this colleagues are humans so they need some distractions or make a nap to continue to work.

**Steps to begin** : 
- Create colleague class
- create first colleague
- create functions to discuss() and to rest()
- create a penalty at each turn to decrease needs
- apply functions to see increase of needs



**Evolutions** :
- A discussion is between two colleagues and must decrease (differently) energy bar (as speacking takes energy) but increase social bar.
- Create a Generator to generate hundred of colleagues with random values of energy and social.
- Create a database with ids to each colleague and create connexions between colleagues.
